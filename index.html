What is live

Confidential balances
Amounts are stored encrypted onchain. An explorer shows that an account holds something, not how much. Grant a counterparty, an auditor, or a tax preparer the key to decrypt yours — and revoke it.

How that works roadmap

  1. Submit. Both sides send encrypted amounts. Neither the network nor an observer sees the figures.
  2. Verify. The contract proves the trade balances while the amounts stay encrypted throughout.
  3. Settle. Encrypted balances update. The transaction is public and auditable; the numbers inside it are not.

Where this stands

The confidential balance contract is live on Ethereum Sepolia and source-verified. Balances are encrypted at the contract level; an address without permission cannot read them.

A threshold proof also works: a verifier can learn whether a balance clears a given figure without learning the balance itself. Contract: 0x1132…DE9c7a.

Testnet only — no real assets, no mainnet deployment, no audit. The agent interface described above is not built yet.
